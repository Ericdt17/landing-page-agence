# Captures des pull requests

Branche d'images uniquement, sans code : captures avant / après affichées dans
les descriptions des PR de la refonte. Ne pas fusionner.

Chaque dossier `prNN/` contient des paires `<vue>-avant.png` / `<vue>-apres.png`,
prises sur le build de production de la branche de base et de la branche de la PR.
